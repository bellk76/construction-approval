# Система согласования заявок (прототип)

Прототип ядра внутренней системы генподрядчика: **управление заявками, маршруты
согласования, лимиты полномочий, права доступа и аудит**.

Собран, чтобы показать подход, а не как готовый продукт: главная ценность —
перенос регламентов согласования в логику системы.

## Что демонстрирует

- **Маршрут строится автоматически** по типу документа и сумме.
- **Согласование по ролям**: шаг согласует только роль из маршрута.
- **Последовательность**: следующий шаг недоступен, пока не согласован предыдущий.
- **Лимиты полномочий**: превышение суммы блокирует согласование.
- **Права**: RBAC + роли по должности + доступ к объектам (data scope).
- **Аудит**: журнал «кто / что / когда» по каждому действию.

## Архитектура

```
web/     React + TypeScript (клиент)
server/  NestJS + Prisma (сервер приложений, модульный монолит)
         PostgreSQL (в прототипе — SQLite, переключается в schema.prisma)
```

Выбор обоснован под условия: небольшая команда, неясная спецификация,
критична целостность процесса. Один язык (TypeScript) на клиент и сервер,
декларативные правила вместо зашитой логики, версионирование правил.

## Стек

| Слой | Технология |
|---|---|
| Клиент | React 19, TypeScript, Vite |
| Сервер | NestJS, Prisma |
| БД | SQLite (прототип) → PostgreSQL (прод) |
| Аутентификация | серверные сессии, httpOnly-cookie |
| Авторизация | RBAC + оргструктура + доступ к объектам |

## Запуск

### Сервер

```bash
cd server
npm install
npm run migrate      # prisma migrate dev
npm run seed         # роли, права, должности, пользователи, правила
npm start            # http://localhost:3000
npm run demo         # сквозной сценарий с проверками
```

### Клиент

```bash
cd web
npm install
npm run dev          # http://localhost:5173 (проксирует /api на :3000)
```

### Скриншоты и видео сценария

```bash
cd web
npx tsx e2e/capture.ts     # прогон UI + скриншоты + видео в web/shots
```

## Правила маршрута (демо-данные)

| Сумма | Маршрут |
|---|---|
| до 300 000 ₽ | 1 шаг: снабжение |
| 300 000 – 1 000 000 ₽ | 2 шага: ПТО → бухгалтерия |
| свыше 1 000 000 ₽ | 3 шага: ПТО → бухгалтерия → директор |
